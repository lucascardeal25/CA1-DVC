# AI Employment in the USA: Data Visualisation CA

Jupyter notebook that visualises employment and wages in AI, Data Science and Software Development occupations in the USA, using the BLS Occupational Employment and Wage Statistics (OEWS).

**Student:** Lucas Alves Ribeiro (2023315), CCT College Dublin

## Files

| File | Description |
|---|---|
| `CA_AI_Employment_USA.ipynb` | Main notebook with 9 visualisations, explanations and the trends challenge |
| `bls_oews_national_2019_2022.csv` | National estimates for May 2019 to May 2022 taken from the BLS OEWS national tables (used for the trends over time) |

## How to run

1. Download the May 2023 "All data" file from https://www.bls.gov/oes/tables.htm (file `oesm23all.zip`) and extract `all_data_M_2023.xlsx`. It is not included here because it is larger than 80 MB.
2. Put `all_data_M_2023.xlsx` in the same folder as the notebook and the CSV.
3. Open the notebook in Jupyter or Google Colab and run all cells (needs pandas, matplotlib, seaborn and openpyxl).
